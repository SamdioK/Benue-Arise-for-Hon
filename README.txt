BENUE SDP CAMPAIGN WEBSITE STARTER
=================================

Files
- index.html: campaign landing page
- register.html: registration / expression-of-interest page inspired by the structure of the reference registration page
- privacy.html: draft privacy notice
- styles.css: responsive styling
- app.js: mobile navigation and demo-only form validation

IMPORTANT
1. The registration form is currently DEMO ONLY. It does not send, store, or transmit submissions.
2. Before collecting real data, connect a secure backend (for example, a properly configured Supabase project), add server-side validation and spam protection, set restrictive database access policies, and have the campaign approve its privacy notice.
3. Verify the candidate's official name, party designation, campaign contact information, manifesto, logo, approved photos, and all public claims before launch.
4. Replace the abstract artwork with an authorised candidate photograph if available. Do not use a photo without permission.
5. Review the privacy and data-handling design against the Nigeria Data Protection Act 2023 and obtain appropriate legal advice.
6. This template is not affiliated with FixNaija Movement and does not copy its source code or branding.

Local preview
Open index.html in a browser. For hosting, upload the contents of this folder to GitHub Pages or another static host. A static host alone will not process form submissions.
